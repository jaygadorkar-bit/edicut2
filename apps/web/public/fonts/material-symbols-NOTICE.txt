Material Symbols font subset

The font at /assets/material-symbols-v383.woff2 is a 137-icon subset generated
by the Google Fonts API from the EdiCut icon-name list in app/lib/material-symbols.ts.
It is hosted locally for performance. The CSS is adapted to use the local font URL.
