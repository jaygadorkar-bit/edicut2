# EdiCut — Unified UI Design & Feature Planning
Status: Finalized implementation strategy

╔═══════════════════════════════════════════════════════════════════════╗
║                    GLOBAL DESIGN SYSTEM                               ║
╚═══════════════════════════════════════════════════════════════════════╝

- Aesthetic: Clean, modern, premium dark cinematic interface.
- Palette: 
    - Base: Deep Obsidian (#0D0D0D)
    - Accents: Electric Cyan (#22D3EE) / Slate Grays (#1E293B, #334155)
- Borders & Corners: Rounded-xl (12-16px) with subtle border-white/10 or border-slate-800.
- Effects: Glassmorphism (heavy backdrop blurs) for nav/panels, soft shadow-2xl for depth.
- Navigation: Top sticky nav for public pages, collapsible sidebar for dashboards.

╔═══════════════════════════════════════════════════════════════════════╗
║                    CONFIRMED PRODUCT DECISIONS                        ║
╚═══════════════════════════════════════════════════════════════════════╝

1. Flow: Pricing catalog -> Package product page -> Buy/Login flow.
2. Roles: Customer, Editor, Project Manager, Admin.
3. Video Review: Frame-level review with drawing/comment tools.
4. File Handling: Large direct upload workflow integrated with dashboards.
5. Communication: Group-chat oriented project workspace.
6. Packages: Marketplace-style product pages for Basic, Medium, and Pro tiers.
7. Payments: Manual-first (receipt upload), gateway integration later.

╔═══════════════════════════════════════════════════════════════════════╗
║                    SITEMAP & PAGE BREAKDOWN                           ║
╚═══════════════════════════════════════════════════════════════════════╝

PUBLIC PAGES
------------
- Home (/) - Full landing flow with cinematic hero.
- Pricing (/pricing) - Package catalog showing all available tiers.
- Package Product (/pricing/[slug]) - Dedicated Fiverr-style detail pages.
- Portfolio (/portfolio) - Bento-grid showcase of previous work.
- About (/about) - Team vision and studio snapshots.
- Contact (/contact) - High-fidelity inquiry form.

CUSTOMER DASHBOARD (/dashboard)
-------------------------------
- Overview: Project status (Pending/Progress/Done) and activity feed.
- Projects (/projects): Kanban or list board of all active edits.
- New Project (/new): 4-step wizard (Package -> Brief -> Upload -> Payment).
- Chat (/chat): Direct communication with the assigned editor.
- Review (/review): Large video player with annotation/canvas tools.
- Billing (/invoices): Payment history and manual receipt uploads.

ADMIN & PM DASHBOARD (/admin)
-----------------------------
- Overview: Revenue metrics and project volume charts.
- Master Board (/projects): Global overview of all client projects.
- Package Editor (/packages): Tool to modify pricing and features.
- User Management (/users): Control over customers and staff roles.
- Finance (/finance): Payment approval and verification workflow.

╔═══════════════════════════════════════════════════════════════════════╗
║                    PAGE SEGMENT DETAILS                               ║
╚═══════════════════════════════════════════════════════════════════════╝

HOME PAGE SECTIONS
1. Hero: Moody production background, trust badge, centered headline, Dual CTAs.
2. Trust Strip: Horizontal logo row of partners/clients.
3. Workflow: 3-step grid (Choose -> Upload -> Review) with large icons.
4. Differentiators: 4-card grid (Team, Speed, Retention, Repurposing).
5. Portfolio: Bento-grid with hover-play video thumbnails and proof cards.
6. Testimonials: Compact stats row + 3-card carousel of client feedback.
7. Pricing: 3-column tiered cards with checklist and product page links.
8. FAQ: objection-handling section (Onboarding, content types, revisions).
9. Final CTA: Conversion panel with pricing/contact buttons.

PACKAGE PRODUCT PAGE SECTIONS
1. Product Hero: Title, badge, review stars, and highlight stats.
2. Sticky Buy Card: Price, delivery speed, revisions, and "Buy Now" button.
3. Gallery: Visual showcase of what this specific package produces.
4. About & Use Cases: Detailed scope framing and "Best For" scenarios.
5. Deliverables: List of what the client receives.
6. Seller Snapshot: Trust block for the support/editor team.
