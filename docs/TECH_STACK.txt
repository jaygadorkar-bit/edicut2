EdiCut Tech Stack
=================

Current repository shape
------------------------
- Frontend: apps/web
  - React 19
  - React Router 7
  - Vite
  - Tailwind CSS 4
  - Cloudflare Worker deployment via Wrangler
- Platform services
  - Supabase Auth and Supabase PostgreSQL for hosted identity/data
- Cloudinary for managed image delivery and transformations
- A separate Cloudinary account for portfolio video storage and delivery
  - Cloudflare Workers for the production edge runtime and custom domains
- Backend API: apps/node-api (local/compatibility service)
  - Hono
  - Node.js local runtime
- Shared packages:
  - packages/shared for contracts and shared content
  - packages/db for the existing Drizzle query layer over the Supabase PostgreSQL connection
  - packages/platform-core for shared application logic
- Database: Supabase PostgreSQL, with local Supabase CLI migrations under `supabase/`
- Authentication: Supabase Auth is preferred when `SUPABASE_*` runtime variables are configured; the signed legacy session path remains available for local migration compatibility

Standard local ports
--------------------
- Web: http://localhost:3000
- Node API: http://localhost:8787/api/node
- Supabase local API: http://127.0.0.1:54321
- Supabase local Postgres: localhost:54322

Design system
-------------
- Aesthetic: clean, minimal, modern white theme tailored for YouTubers
- Homepage hero background: plain white (#FFFFFF), with no hero image or decorative media block
- Typography: Roboto with system sans-serif fallbacks
- Palette:
  - White: #FFFFFF
  - Light gray: #F9F9F9
  - YouTube red: #FF0000
  - Deep black: #0F0F0F
  - Neutral grays: #717171, #282828
- UI: rounded 12-16px corners, subtle borders, restrained shadows, sticky glass public nav
- Homepage composition: include a portfolio section in the middle of the page and a dedicated Contact Us section at the bottom

Frontend source of truth
------------------------
- Home route: apps/web/app/routes/home.tsx
- Dashboard route: apps/web/app/routes/dashboard.tsx
- Dashboard feature plan: docs/DASHBOARD_FEATURES.md
- Routes: apps/web/app/routes.ts
- Global styles: apps/web/app/styles/global.css
- Worker entrypoint: apps/web/workers/app.ts

Commands
--------
- Install: pnpm install
- Frontend dev: pnpm dev
- API dev: pnpm dev:node-api
- Typecheck: pnpm typecheck
- Build: pnpm build
- Supabase local stack: npx supabase start
- Docker: docker compose up --build

Provider configuration
---------------------
- Browser build variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`
- Cloudflare Worker secrets: `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`, `CLOUDINARY_VIDEO_CLOUD_NAME`, `CLOUDINARY_VIDEO_API_KEY`, `CLOUDINARY_VIDEO_API_SECRET`
- Apply the database schema with `npx supabase db push` after linking the hosted project.
