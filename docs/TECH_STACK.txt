EdiCut Tech Stack
=================

Current repository shape
------------------------
- Frontend: apps/web
  - React 19
  - React Router 7
  - Vite
  - Tailwind CSS 4
  - Cloudflare Worker deployment via Wrangler
- Backend API: apps/node-api
  - Hono
  - Node.js local runtime
- Shared packages:
  - packages/shared for contracts and shared content
  - packages/db for Drizzle/PostgreSQL access
  - packages/platform-core for platform/auth-oriented shared logic
- Database: PostgreSQL locally through Docker, Neon-compatible Drizzle layer for hosted environments

Standard local ports
--------------------
- Web: http://localhost:3000
- Node API: http://localhost:8787/api/node
- Postgres: localhost:5432

Design system
-------------
- Aesthetic: clean, minimal, modern white theme tailored for YouTubers
- Homepage hero background: plain white (#FFFFFF), with no hero image or decorative media block
- Typography: Roboto with system sans-serif fallbacks
- Palette:
  - White: #FFFFFF
  - Light gray: #F9F9F9
  - YouTube red: #FF0000
  - Deep black: #0F0F0F
  - Neutral grays: #717171, #282828
- UI: rounded 12-16px corners, subtle borders, restrained shadows, sticky glass public nav
- Homepage composition: include a portfolio section in the middle of the page and a dedicated Contact Us section at the bottom

Frontend source of truth
------------------------
- Home route: apps/web/app/routes/home.tsx
- Dashboard route: apps/web/app/routes/dashboard.tsx
- Dashboard feature plan: docs/DASHBOARD_FEATURES.md
- Routes: apps/web/app/routes.ts
- Global styles: apps/web/app/styles/global.css
- Worker entrypoint: apps/web/workers/app.ts

Commands
--------
- Install: pnpm install
- Frontend dev: pnpm dev
- API dev: pnpm dev:node-api
- Typecheck: pnpm typecheck
- Build: pnpm build
- Docker: docker compose up --build
